# IMU-Controlled-Mobile-Robot-
Developed an IMU-controlled wireless mobile robot using Arduino, MPU9250, and PID control. The robot was operated through hand gestures, with encoder-based closed-loop motor control for improved stability. MATLAB/Simulink was used to model and analyze the system, including transfer function, root locus, and Bode plot analysis.
